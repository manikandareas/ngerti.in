## Tujuan

Identitas dan percakapan produk persisten di atas dua runtime wajib, Codex/ChatGPT dan Muse Code, termasuk perubahan agent melalui tools dari percakapan. Runtime tambahan tidak menjadi prasyarat.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — C01, C02, C03, C04, B04, H01.

## Unit implementasi

1. Atomic dev setup Tobi + primary DM + authored welcome; normal opening tidak memanggil model.
2. Agent/profile/revision/provider selection serta session binding per thread; domain tools create/update agent.
3. Conversation snapshots/history/event APIs dan explicit author mapping.

## Acceptance criteria

- [x] Concurrent setup/retry menghasilkan satu Tobi dan satu primary DM; welcome tidak terulang atau memicu model.
- [x] Nama/soul/instructions/skills/model terpisah dari native runtime state dan tetap konsisten lintas DM/grup.
- [x] Agent dapat membuat/mengubah konfigurasi melalui produk-tools dengan scope/revision checks; tidak perlu form wajib.
- [x] Perubahan config memengaruhi pekerjaan berikutnya sesuai snapshot contract, bukan mengubah run aktif tanpa jejak.
- [x] Riwayat, agent/thread ID dan native mapping bertahan restart; opening/reconnect tidak menghasilkan pesan/run ganda.
- [x] API/schema/examples siap dikonsumsi tanpa mengubah UI pada tiket ini.
