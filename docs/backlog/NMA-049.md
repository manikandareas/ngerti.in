## Tujuan

Menghubungkan Codex yang terpasang melalui protocol native yang sesuai, dengan ChatGPT plan sebagai jalur subscription untuk agent Ngertiin. Opsi API key tetap tersedia bila didukung dan dipilih secara eksplisit.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — PR01.

## Unit implementasi

1. Codex melalui native App Server; bandingkan adapter ACP hanya bila menghasilkan kebutuhan kontrak yang lebih baik.
2. Login ChatGPT plan dan optional API key mengikuti dukungan Codex; credential efektif serta sumber billing harus jelas tanpa fallback diam-diam.
3. Mapping provider model, settings, streaming, tool bridge, resume, cancellation dan request ownership. Claude Code berada pada rencana Ditunda, bukan scope tiket ini.

## Acceptance criteria

- [x] Codex/ChatGPT menjalankan satu completed subscription-backed request dan satu produk-tool round trip melalui API Ngertiin; akses plan yang belum tersedia membuat acceptance ini tetap terbuka.
- [x] Subscription/key behavior yang tersedia diuji terpisah; akun berhasil login tidak dihitung sebagai inference pass.
- [x] Native session ID dan history binding bertahan pada restart; tidak ada transcript yang menyilang DM/grup.
- [x] Steer/cancel/permission dan setting yang didukung diproyeksikan ke kontrak broker; fitur tidak didukung terlihat sebagai capability.
- [x] Versi SDK/CLI minimum dan tested versions dicatat; failures/skips/akses akun yang belum tersedia tidak disembunyikan.
