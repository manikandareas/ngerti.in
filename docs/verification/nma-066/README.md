## Failures and performance

The initial recursive-schema compilation crash on an AppKit small stack was fixed by one bounded eight-MiB OS worker and a separate small-stack regression. The initial single-page/PDFKit continuous-view layout limitations were superseded by the current GPUI continuous viewport with Quartz rasters/PDFKit text. The incorrect Quartz upscaling and absolute overlay origins were reproduced and corrected before the retained selection evidence. These corrections are not inferred from unit tests alone; native captures retain the observed result.

The first avatar iterations confused frequent window redraw with actual content updates. Debug scalar rasterization and bicubic/native scheduling iterations are retained as failures. Current instrumentation separates compositor CPU work, delivered-image intervals, native framework draw/work/presentation and explicit process CPU/RSS. A missing queued display callback caused half-rate delivery; registering the next callback before awaiting the worker restored approximately 60 actual updates/second in the first completed 120-second case. A subsequent user scene change correctly retired the benchmark; that interrupted cohort is retained separately and is not a full matrix pass. The complete eighteen-sample native/original-engine Tauri avatar matrix subsequently passed its recorded framework/process budgets at the matched observed viewport/scale; activation and cadence limits remain in the component report. Additional measurement stopped under the owner decision.

[Workloads/budgets](../../../apps/desktop-rs/verification/performance-workloads.json) retain the original engineering targets, with incomplete cohorts non-blocking for this closure: 20 cold/20 warm launches, 120-second sustained cases, 60-second hidden windows, first-conversation p95 1500 ms, frame work p95 16.67 ms, missed refreshes ≤1%, hidden CPU ≤1%, matched RSS ratio ≤1.1. Avatar component evidence does not establish streaming/history/tree or integrated conversation performance. No GPU-only speed/memory claim is made.
