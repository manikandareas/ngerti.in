## Objective

Deliver the reusable components that carry Ngertiin's identity and difficult editing/rendering behavior before composing live product workflows. Follow the selected rendering paths and [parity contract](../architecture/desktop-rs-plan-2026-11-07.md#parity-contract).

## Implementation units

1. Port recipe parsing/versioning, 32-bit seeded random behavior, body geometry, colors and fur generation to the Rust avatar crate. Separate cached material/texture from dynamic eyes, pose and ornaments. The desktop adapter owns GPUI drawing/input.
2. Port expression/state mapping, idle breathing, gaze/head smoothing, independent blink, actions, loading rings/veins, reduced motion and visibility-aware clocks. Preserve original texture/filter appearance and transparent SVG/PNG export; resolve the experiment's omitted eye-shadow effect.
3. Build the native composer model and view: multiline text, mention/file/skill references, suggestions, cursor/selection, deletion, undo/redo, IME composition, Unicode/graphemes, clipboard/files and focus restoration. Keep editing state separate from submission/network policy.
4. Implement bubbles, attribution, activity, clocks/day markers, question/approval controls, reference/source links, attachment rows and reusable error/retry presentation. Cover user/assistant, DM/group and file-only messages.
5. Implement Markdown/GFM, code, image, CSV/TSV/table, source, PDF and static HTML presentation components. Preserve syntax palette, selection/copy/download, table sorting/filtering/wrapping/expanded view, source find/wrap/line numbers, and the current preview limits. Use the NMA-066-selected native PDF adapter with GPUI interaction/controls. Only the static HTML document body may use the isolated browser adapter; follow the [rendering ownership contract](../architecture/desktop-rs-plan-2026-11-07.md#rendering-ownership-contract).

## Acceptance criteria

- [ ] The same versioned recipe yields matching seeded shape/color/face/fur identity, including Unicode seeds and legacy valid colors. A Rust executable generates new avatars without invoking the TypeScript renderer or switching pre-exported full portraits per state.
- [ ] All current shapes, expressions, states and transient actions are compared at fixed timestamps. Gaze, blinking, loading, pause/reduced motion, hidden/offscreen suspend and transparent exports are verified independently of a static screenshot.
- [ ] Fine fur, gradients, silhouette and eye contact/inset shadows match the agreed visual baseline; any unresolved renderer difference is retained explicitly. Full avatar behavior is not inferred from the earlier cached-image experiment.
- [ ] Composer editing preserves token boundaries and metadata through select/copy/cut/paste, undo/redo, insertion/deletion and multiline edits. Enter/Shift+Enter, active IME composition, emoji/combining text and focus handoff are exercised on the native host.
- [ ] Gallery fixtures cover attribution, clocks, loading/waiting/failure/settled states, reference chips and file-only messages in both themes. No raw tool observations or private handoff instructions are exposed.
- [ ] Native rich tables/source preserve original copy/export content. PDF supports paging, selectable text, 50–200% zoom/fit-to-width and reading-position retention; malformed/protected/oversized content yields actionable retry/download states.
- [ ] Reads and rendering retain the reference limits: 128,000-byte text preview, readable fallback above 100,000 highlighted characters, virtualization above 500 source lines, 16 MiB PDF/500 pages and bounded nearby page canvases. Static HTML blocks scripts, forms, external resources/navigation and credential access while original downloads remain unchanged.
- [ ] Many-avatar/content workloads are measured against the NMA-066 budgets. Parsing/texture generation is off the UI thread, caches are bounded, and unused/offscreen work retires. Component evidence passes before real API screen composition begins.
- [ ] Composer, messages, Markdown/table/source, PDF controls and avatar presentation are native Rust/GPUI. Runtime rendering does not invoke React, Lexical, PDF.js or the TypeScript avatar engine; original assets and reference fixtures retain their provenance.
