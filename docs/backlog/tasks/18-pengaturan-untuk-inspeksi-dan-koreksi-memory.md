## Hasil

Pengguna dapat mengelola memory terkurasi melalui pengaturan.

## Acceptance criteria

- [ ] Tampilkan entry memory, konteks dan evidence yang dapat dipahami pengguna.
- [ ] Koreksi/forgetting tersimpan dan bertahan setelah refresh maupun background curation.
- [ ] Batas tindakan pada memory, history, materi dan progress jelas; editing memory tidak mengubah completion belajar.
