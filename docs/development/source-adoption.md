## Evidence levels and upgrade procedure

Distinguish decisions, source observed, contract/fixture tests, native/live operation, API readiness, UI verification and distribution. A source benchmark or supported interface alone does not prove Ngertiin behavior. Login, discovery, inference and useful product-tool execution remain separate observations.

For an upgrade, compare the exact adopted modules/protocols and dependency pins, adapt only the selected seams, regenerate changed contracts, and rerun affected fixture/process/native/browser checks. New upstream features do not become scope automatically. Preserve versioned artifacts and failure/skip/unknown boundaries. Source and SDK changes do not justify silent billing fallback, overwriting inherited skills or importing private DM context into a group.

[The foundation ADR](../architecture/adr-0001-harness-first-foundation.md) and per-milestone provenance preserve original adoption facts; [history](history.md) explains retired source lookup.

The shared control adapter also depends on the exact 0.9.0 `button/button.rs`, `radio.rs`, `tab/tab.rs`, `gpui-base/src/radio_group.rs` and `gpui-base/src/tabs.rs` contracts. Overlay titles/descriptions receive explicit accessible roles/labels. The disabled Input rejects focus/editing, but its underlying editor accessibility node currently omits the disabled flag. Recheck native keyboard, focus, disabled/selected states, accessible roles and both product themes before upgrading these modules.

GPUI Fast **0.1.13** `elements/div.rs` maps vertical wheel delta to a horizontal-only overflow container unless `restrict_scroll_to_axis` is enabled. The native table explicitly restricts the axis after reproducing vertical scrolling that also displaced columns. Native vertical scroll and horizontal keyboard movement now have separate proof. The table's horizontal column window retains total width and one neighboring column on each side; a bounded 256-row cache uses GPUI's `shape_text`/wrapped-line geometry across all columns to preserve wrapped row height. Upgrade checks cover viewport edges, resize/wrap/filter invalidation, horizontal movement, selection/copy and long wrapped cells. Development profiles explicitly optimize the pinned rendering/layout, native accessibility, Lyon tessellation and native Apple rendering backend packages; record these overrides with each binary and do not present them as a release build. The local disabled-field semantic wrapper follows the Element delegation in `gpui-base-0.9.0/src/a11y_disabled.rs`. The source highlighter adapts `gpui-component-0.9.0/src/highlighter/syntect_backend.rs` (Apache-2.0) parse/scope logic, with Syntect **5.3.0**/two-face **0.4.5**.
