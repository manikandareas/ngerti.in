# Native media adoption — NMA-037

Implementation date: 28 October 2026. Local development delivery; no production deployment, original-account migration, commit or push.

## Amended scope

The user explicitly authorized completing this ticket without implementing video generation/edit/extension or TTS generation because OpenAI credits are exhausted. These capabilities are unimplemented, not simulated or counted as successful. Consequently there is no long-running video-generation job scheduler, TTS voice selection, spoken-response replay or TTS barge-in contract in this delivery. Speech input uses push-to-talk/voice notes and ordinary conversation text responses, with the existing native admission/cancellation authority.

Implemented configured operations: uploaded/pasted images, compatible primary vision or explicitly granted auxiliary Muse vision, image generation/editing, uploaded/user-posted HTTPS video analysis, voice-note/microphone capture, native transcription and retained media playback/download. Meta Model API is the configured direct provider, using the supplied key only in disposable test-owner vaults.

## Architecture and public contracts

Hermes remains pinned at `7489b22af47ce91b366dde81d5831ea422577498` (MIT); upstream sources are unmodified. Source hashes cover the adopted native media, provider, transcription and image-admission seams. Existing owner/agent/thread/config identities, text messages, history, goals, skills and receipts are preserved. Schema remains 20; no historical migration was changed.

- `media_inputs.py` validates decoded image bytes and reauthorizes immutable artifact IDs on admission/recovery. A compatible primary receives native Hermes image attachments and its immutable admission capture. Text-only/unknown primaries require the explicitly assigned Muse vision route and receive scoped artifact references with inspection instructions. Missing routes fail with `MEDIA_ROUTE_UNAVAILABLE`; malformed images fail with `UNSUPPORTED_MEDIA`. DM/group input retains original product attachment IDs. Group attachment metadata stays outside the native planner's strict event schema.
- `media_provider.py` adapts the pinned OpenAI-compatible Hermes image backend to Meta's `muse-image-1.0`. Native prompt/aspect fields are retained; references become `artifact:<id>`, not host paths. Generation/edit outputs are MIME-sniffed into immutable hashed files and `artifact.ready` events. Native output may be WEBP despite a `.png` cache filename; publication uses bytes and references use MIME-correct data URLs. Unsupported controls, including upscaling, are rejected explicitly.
- `media_analysis.py` retains native `vision_analyze_tool`/`video_analyze_tool` preparation, result and error behavior. A context-local auxiliary call uses `muse-spark-1.3` with direct Meta credentials. Tool schemas support scoped artifacts; video may import an HTTPS URL explicitly posted by the user in the current thread/context generation. `media_sources.py` uses Hermes's connect-time SSRF/redirect guard, no ambient proxy credentials, a 32 MiB limit and one retained import. Local/private URLs and model-invented references are refused. External URL import has deterministic contract coverage; actual provider understanding was exercised with uploaded media.
- `speech.py` registers `nma-meta` through Hermes's native transcription provider registry. It invokes public native `transcribe_audio`, using Meta's `muse-voice-transcribe-1.0` file endpoint. FFmpeg normalizes uploads to mono 16 kHz signed PCM WAV; input comes through a pipe with only the pipe protocol allowed, no provider environment and a ten-minute validation ceiling. Video metadata uses FFprobe with the same input confinement. These are media codecs, not another agent executor.
- A durable transcription intent is committed before the billable request in the existing owner operation journal. Request-key/payload conflicts are refused; completed or indeterminate receipts are reused across reconnect/restart. A lost ACK never automatically submits another request. Generation uses existing native effect receipts and explicitly disables SDK POST retries; ambiguous results remain unknown. No universal exactly-once guarantee is claimed.
- Secret-bearing setup uses authenticated `GET/POST/DELETE /api/agent-engine/v1/apps/media`; keys live only in the owner-private vault. Agent grants `media_images`, `media_vision`, `media_video` freeze generation/schema/surface fingerprints. Public `media.transcribe` accepts artifact/thread/request identities. Configuration/disconnect use the private command path and do not enter the generic event/command journal.
- Web Connections includes media setup. Composer supports file/image paste and microphone recording; recording needs an explicit browser permission request. Audio uploads yield a transcript draft associated with the retained attachment. Sending uses the existing durable message identity; capture alone does not submit a user turn or cancel goal work. Removed/sent attachments cannot receive a late transcript draft. Cancellation/unmount stops only the recording tracks. Denial/provider/network failures retain ordinary text interaction. Audio/video previews use authenticated bytes and native browser controls; blob URLs are revoked.

## Reproduction and configured limits

Root `.env` may contain `MUSE_API_KEY` for opt-in tests; it is not automatically installed into every tenant. Connect an owner's Meta key in Connections and assign the required agent media grants. No Nous Tool Gateway is used. `ffmpeg` and `ffprobe` must be installed; exact local build/license information is retained in evidence. System codec binaries are invoked, not bundled by this change.

Run with pinned source/runtime and `apps/engine/src` on PYTHONPATH. `NMA_TEST_MUSE=1` enables the three paid live tests in `apps/engine/tests/test_media.py`; these require `.dev/nma037/speech.wav` and `video.mp4` fixtures. `scripts/spikes/nma037/muse_image.py` is a direct native-provider reproduction, and `ui.py` plus `apps/engine/tests/browser/media.config.ts` run the disposable authenticated walkthrough. The ordinary regression leaves paid opt-ins explicitly skipped.

Samples are smoke tests, not the NMA-028/NMA-039 minimum release corpus or a p95/SLO claim. Native versus integration failure rates cannot be inferred from this small heterogeneous cohort. NMA-039/NMA-027 continue to own broader parity and operational release acceptance. Complete conversation composition remains NMA-038.
