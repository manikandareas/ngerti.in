## Tujuan

Agent mengoperasikan browser melalui browser-use MCP langsung pada sesi yang sama dengan visual VNC yang nantinya dilihat pengguna web; login disimpan pada profil persisten yang scope-nya dikelola Ngertiin.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — F06, H03.

## Unit implementasi

1. Integrasi browser-use MCP yang dikelola backend, dengan versi/process configuration terpin, tool/capability allowlist, explicit browser/profile/CDP binding dan scoped routing ke Codex/Muse.
2. Browser host/session lifecycle dan VNC transport pada browser yang sama; canonical session/target, tab focus, status, screenshot/input metadata serta resource API tanpa implementasi UI.
3. Persistensi profil/cookies/storage, credential handling dan resource ownership; akses login tidak membuka credential directory atau profil owner lain ke agent.
4. Sambungkan final authorization, cancellation intent, action receipts dan reconnect/recovery ke lifecycle aplikasi yang sudah ada. Bedakan stop run, detach MCP, menutup browser dan reset profil; stop run tidak otomatis menghapus login.
5. Dokumentasikan kontrak API, konfigurasi host, capability/unsupported/unknown states dan contoh client/CLI untuk fase UI. Detail VNC transport serta minimum/tested versions ditutup dengan bukti pada implementasi.

## Acceptance criteria

- [x] Browser-use MCP terhubung melalui jalur aplikasi untuk kedua runtime wajib Codex/ChatGPT dan Muse Code; useful open/navigate/fill/read action menghasilkan observasi DOM/screenshot dan hasil yang dapat diperiksa. Tidak memakai autonomous browser-use Agent atau model/API-key fallback tersembunyi.
- [x] Action nyata dan tampilan VNC memakai host, browser profile, session dan target/tab yang sama; binding serta perpindahan tab/focus dapat diverifikasi melalui API/test client. Screenshot/path atau koneksi CDP saja tidak dianggap bukti sesi visual yang sama.
- [x] VNC menunjukkan browser pada host yang benar; tidak menganggap desktop laptop tersedia dari backend lain. VNC tetap transport host terpisah dari library kontrol browser.
- [x] Login/cookies/storage pada profil yang sama tetap dapat digunakan antar-run dan sesudah restart browser/backend yang didukung, tanpa login ulang selama sesi situs valid. Expiry/revocation menghasilkan auth-required; profil milik scope lain tidak terbaca atau terpakai tanpa sharing eksplisit.
- [x] Akses VNC/browser tidak otomatis memberi izin tindakan eksternal. Grant/capability diperiksa kembali pada final dispatch; perubahan grant, foreign session/target/profile, stale lease dan resource/screenshot access diuji. Secret dan isi profil tidak dipublikasikan ke transcript/log atau workspace umum.
- [x] Restart/reconnect/stop merekonsiliasi receipt dan binding sebelum melanjutkan; hasil tindakan unknown tidak diulang buta. Late dispatch setelah stop/revoke ditolak. Stop run, detach, browser close dan reset profil mempunyai semantics yang terdokumentasi; confirmed stop dibedakan dari stop-requested/unknown.
- [x] Endpoint/transport contract, session/auth/error/capability states, konfigurasi profile/CDP/VNC dan contoh client siap untuk UI setelah NMA-060. Tab/popup, frame, upload atau kemampuan lain hanya diiklankan bila benar-benar diverifikasi pada versi yang dipakai.
- [x] Catat useful task success, retries/errors/unknown outcomes dan latency sesuai cohort/denominator yang dijalankan, termasuk waktu setup terpisah dari action/task completion. Jangan mengklaim paling cepat atau error rate rendah hanya dari benchmark upstream.
- [x] F07 general desktop/computer use, native macOS/Windows clients, remote/multi-host dan browser cloud berbayar tidak menjadi dependency baru. Tidak mengubah UI atau installer pada tiket ini.
