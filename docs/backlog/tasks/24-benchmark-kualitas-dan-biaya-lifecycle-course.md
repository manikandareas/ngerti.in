## Acceptance criteria

- [ ] Benchmark Course pendek/sedang/besar serta sumber tidak memadai; jumlah node/aktivitas tetap mengikuti standar.
- [ ] Human review menilai Lesson, evidence, soal/key dan pengayaan; hasil otomatis dibedakan dari penerimaan manusia.
- [ ] Catat token/model, parsing/OCR, retrieval, grading, repair, memory/proaktif dan kegagalan per Course/akun.
- [ ] Target sekitar Rp2.000/Course dinilai sebagai target; biaya Free, P50/P90 dan kontribusi paket Rp49.000/5 Course diukur sebelum publikasi.
