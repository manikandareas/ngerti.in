The retained native GUI is an ad-hoc development bundle using the explicit remote profile `Ngertiin Demo NMA082`; its secure-store relaunch and actual desktop/file rendering are recorded separately from the headless gateway admissions. The original local Ngertiin backend remains stopped after its selected application-managed Codex authority was transferred. Global Codex history/credentials, other local profiles and other server applications were preserved. General installation and the wider NMA-083 journey matrix are outside this receipt.

The final off-host transfer was resumed only after comparing the interrupted encrypted prefix with the server. Per-command `IPQoS=none` improved the observed SSH transfer without changing SSH encryption or modifying the user's SSH configuration. Incomplete ciphertext failed authenticated verification; the completed sidecar digest and inventory pass. The demonstrated off-host destination is the operator's FileVault-protected Mac; no automatic replicated retention/PITR policy is inferred.
