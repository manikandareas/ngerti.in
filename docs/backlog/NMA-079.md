## Objective

Publish and verify the complete changed backend contract before web/Tauri consume the new multi-user behavior.

The [main server-organizations plan](../architecture/server-organizations-plan-2026-11-12.md) owns the design, scope defaults, diagrams and privacy model. This milestone records the verified 2.0.0 backend API/isolation gate; the retained report owns its exact evidence and limitations. Targets are the server, web-client and Tauri; desktop-rs source was retired on November 15.

## Implementation units

1. Inventory every API/entity/command/tool/event/viewer and its identity, organization, ownership, visibility, idempotency and error behavior.
2. Choose a justified breaking contract/version transition, regenerate executable export and examples, and document migration from the owner-only consumer contract without changing historical snapshots.
3. Produce an enumerated multi-organization and same-organization cross-user access matrix including receipts, derived files, background responsibilities and connection recovery.
4. Reverify PostgreSQL ordering/recovery, auth/revocation, native Cua isolation and both required harness adapters with distinct fixture/native/billing evidence.
5. Specify consumer onboarding, organization switch, selected connection, errors, stream renewal and disconnect semantics using authoritative responses.

## Acceptance criteria

- [x] NMA-072–078 are complete for their stated scope and the changed export describes all registered surfaces, with explicit public/operator/user/run-lease/ticket authentication classes.
- [x] Every affected surface has positive/negative access results and exact denominator, including private data between two members using one Team agent.
- [x] Commit-ordered cursors, reconnect, lost acknowledgement, membership/grant changes and unknown external effects preserve scope and one durable operation.
- [x] Codex subscription and Muse supported API-key inference/useful product tools are distinct from login/catalog tests; unverified capabilities remain explicit.
- [x] No owner-wide event or generic entity endpoint, privileged database role, MCP route or viewer bypass remains outside the inventory.
- [x] Consumer guides, schemas, provenance, limitations and local backlog agree; the historical NMA-060 acceptance is not relabeled as proof of this delta.

## Verification and evidence

HTTP/headless/native contract gate with disposable database/actors plus retained exact-version provider/machine observations.

The [verification report](../verification/nma-079/README.md) retains the [2.0.0 contract](../contracts/2.0.0.json), 145/145 enumerated HTTP access-policy cases, 142/142 protected-route missing-credential denials, 37 entity kinds, PostgreSQL/auth/revocation/replay results, native Cua checks and four normal native Codex/Muse inference/tool lanes. Successful operations and expected state/method restrictions are explicit.

The broad regression passes 541/541 tests. Final callback/notification/credential scope changes have a separate 59/59 affected cohort and an explicit revoked-native-timeout regression; the final native reports retain exact runtime hashes. The [consumer guide](../architecture/server-organizations-api.md) specifies the breaking version transition and consumer semantics. Full documentation checking retains eight unchanged imported GPUI guide link failures; the bounded documentation check verifies the rest without changing those files. No browser/Tauri UI, deployed HTTPS, installation or capacity acceptance is claimed.
