## Tujuan

Satu pengguna dan beberapa agent berkolaborasi lintas harness, dengan pemilihan penjawab berbasis konteks dan agent lain tetap diam.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — D01, D02, D03, D05.

## Unit implementasi

1. Group membership, explicit authorship dan scoped shared context.
2. Model-router contract; mention dan model memilih target valid, Jev/System One hanya kandidat implementasi.
3. Peer tasks/handoff/review dan mention pengguna untuk input/approval/HITL; durable reply/resume binding.

## Acceptance criteria

- [x] Dua agent berbeda harness menyelesaikan satu handoff/review nyata dengan author dan task lineage yang benar.
- [x] Agent yang tidak dipilih tidak menghasilkan pass/skip/no-response message atau transcript clutter.
- [x] Router berbasis konteks, bukan random/round-robin wajib; hasil invalid atau agent di luar grup ditolak secara jelas.
- [x] DM/private memory/artifact tidak otomatis ikut ke grup; membership revoke berlaku sebelum queued dispatch.
- [x] Agent dapat meminta pengguna melakukan review/input; pekerjaan terkait menunggu dan respons melanjutkan scope yang tepat.
- [x] Handoff/retry/restart tidak membuat tugas atau pesan ganda; tidak menambahkan multi-human collaboration atau approval universal.
