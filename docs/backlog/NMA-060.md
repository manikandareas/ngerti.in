## Acceptance criteria

- [x] Semua dependency Done dan seluruh fitur backend wajib punya endpoint/event/tool owner serta bukti yang dapat diulang. All eleven prerequisites were fetched live as Done; 47 backend requirements plus the NMA-065 amendment are mapped and verified against contract 1.16.0.
- [x] NMA-065 Done with repeatable creation/collision/retry/reconnect/restart/opening-failure/privacy evidence, useful native opening/scoped-update coverage for both required harnesses, and versioned consumer examples. Existing-chat opening does not invoke inference; group personalization does not rewrite private member profiles.
- [x] Dua runtime wajib saja, Codex/ChatGPT PR01 dan Muse Code PR02, diuji per denominator dan minimum/tested version, termasuk jalur subscription serta key bila dipakai. Credential unavailable atau skipped tetap membuat acceptance terkait terbuka. PR03–PR07 dan NMA-051 ditunda serta tidak menghambat gate ini.
- [x] Alur nyata mencakup DM, grup lintas Codex/ChatGPT dan Muse Code, product tools, goal/Routine offline, browser VNC, Composio dan supported visual input. Final native cohort: 38 runs, 36 succeeded and two cancelled with native confirmation; expected unsupported video rejection is recorded separately.
- [x] Contract tests, concurrency/privacy/cancel/recovery/fault checks lulus; unknown effects dan missing usage tidak dipalsukan. Final suite 246/246 pass; controlled foundation faults 8/8 and broker HTTP 5/5 pass. Final native restart, cancellation, scoped access and offline scheduling are verified separately. Two historical Composio effects remain unknown.

Contract 1.16.0 reviews all 82 route responses, including creation/opening, structured native interactions with tool/choice display fields, nullable workspace, transport and error boundaries. Consumer 6/6 passes; API readiness is ready, supported by the final native cohort.

Removed 310 verified obsolete source/config/tooling files; historical Git revision, archive and hashes are recorded. Data, Docker resources, notices and historical evidence are preserved.
