## Tujuan

Percakapan saat agent sibuk tetap dapat dikendalikan dan dipulihkan, dengan status run yang sesuai native outcome.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — C05, C06, C07, H01, H02, H05, A04.

## Unit implementasi

1. Persist queue/delivery/turn transitions dan streaming events; edit/hapus pesan belum diproses.
2. Jalur Arahkan sekarang dan interpretasi pembatalan oleh native agent melalui structured tools; hapus regex cancellation intent. Endpoint cancel eksplisit tetap independen dari antrean/model untuk harness macet, sesuai keputusan pengguna 2026-10-31.
3. Restart/reconciliation, receipt/dedup, history replay, request timeout/error classification dan diagnostics.

## Acceptance criteria

- [x] Default pesan saat sibuk masuk antrean; steering/cancellation memakai prioritas kontrol dan mapping native yang didukung.
- [x] Edit/hapus pesan tidak dianggap membatalkan tindakan selesai; stop run berbeda dari stop goal dan keduanya punya events yang jelas.
- [x] Maksud stop dipahami oleh native agent dari konteks percakapan/steer dan dieksekusi lewat scoped cancel\_run/goal/Routine tools; backend tidak mengklasifikasikan bahasa melalui regex. Endpoint cancel eksplisit tetap independen. Receipt, scope, stop intent/native confirmation serta native tool proof diverifikasi ulang tanpa mandatory approval.
- [x] Status stop-requested dipisahkan dari native stopped; timeout atau proses putus tidak otomatis menjadi sukses/gagal pasti.
- [x] Crash pada dispatch/tool/commit/publication direkonsiliasi tanpa duplicate effect; events dapat direplay tanpa duplicate message.
- [x] Temporary provider/network failure, terminal auth rejection dan unknown refresh/dispatch outcome tidak disamakan; diagnostics meredaksi secret.
- [x] Semua perilaku dibuktikan melalui engine/API harness tanpa UI.
