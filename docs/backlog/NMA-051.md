## Tujuan

Menyimpan pegangan integrasi runtime tambahan: Claude Code melalui adapter native/SDK, serta Grok, OpenCode, Gemini, Cursor, Cline dan custom ACP melalui jalur yang sesuai. Semua target ini ditunda; aktifkan kembali hanya setelah keputusan scope eksplisit, satu target per kebutuhan.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — PR04, PR05, PR06, PR07; seluruhnya Tunda saat ini.

## Calon unit implementasi setelah dipromosikan

1. Claude native Agent SDK/client atau ACP initialize/auth/config/session/prompt/updates/cancel sesuai provider yang dipromosikan; native identifiers dan process supervision.
2. Provider-specific behavior dan setup host development; custom ACP dapat didaftarkan melalui dev/API configuration.
3. Per-provider capability/version/auth/billing manifest; jangan mengasumsikan v2 dari keberadaan dokumentasinya.

## Calon acceptance setelah dipromosikan

- [ ] Setiap provider yang dipromosikan secara eksplisit memiliki denominator test, versi, hasil request selesai serta produk-tool round trip. Daftar kandidat bukan kewajiban mengimplementasikan semuanya.
- [ ] Pilihan model/account tidak berubah diam-diam karena process-wide settings; concurrent agent/session scope diuji.
- [ ] Text/tool/progress/permission/failure events terstruktur dipetakan tanpa menjadikan error provider sebagai jawaban sukses.
- [ ] Resume/cancel/no-response/restart diuji sesuai capability tiap harness; unknown outcome tidak blind replay.
- [ ] Login host GUI development dapat digunakan sesuai dukungan; VPS/headless compatibility bukan scope wajib saat ini.
- [ ] Custom ACP PR07 tetap ditunda sampai dipromosikan; editor advanced CLI/path/args di UI B07 tetap opsional dan tidak menjadi syarat runtime wajib.
