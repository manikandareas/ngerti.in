## Tujuan

Satu halaman percakapan responsif dengan sidebar agent/chat, pembuatan agent langsung, personalisasi melalui tools, dan panel detail kanan yang mengonsumsi API siap.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — A03, C01, C02, C03, C04, C05, C06, C07, B01, B02, B03, B04, B06, H05, H06, G01, G02, G03, G04.

## Unit implementasi

1. Shell percakapan responsif, entry Tobi/DM, daftar agent/grup/chat di sidebar kiri, dan tombol + dengan popover Create agent/Create group.
2. Create agent langsung memakai command backend untuk nama acak/avatar/default connection/model, membuka DM yang dihasilkan, dan memulai satu pesan pembuka otomatis yang terlihat dari pengguna. Tidak ada form agent wajib atau perantara Tobi.
3. Kerangka sidebar kanan yang dapat ditutup; klik avatar/nama membuka Agent. Profil, peran/instructions, pengaturan bertahap, memory dan harness/app skills berada di sini. Detail File/Goals/Routine serta Anggota grup disambungkan NMA-062.
4. Streaming jawaban/tools, queue Menunggu, edit/delete pesan belum diproses, Arahkan sekarang sesuai capability, conversational stop dan receipt-based configuration feedback.
5. Basic detection/minimum version/account/model/reasoning/capability/billing selection untuk Codex/ChatGPT dan Muse Code; Settings umum dan error repair kontekstual.

## Acceptance criteria

- [x] NMA-060 Done dan mencakup NMA-065 sebelum pekerjaan UI ini dimulai; semua state menggunakan kontrak/API nyata.
- [x] Sidebar kiri sekaligus daftar agent/grup dan percakapan; klik membuka chat. Tidak ada halaman Agents terpisah atau navigasi utama Workspace/Goals/Routine.
- [x] Tombol + membuka tepat dua pilihan Create agent dan Create group. Create group memakai flow NMA-062; tidak ada backend/state simulasi sebagai bukti.
- [x] Create agent tidak meminta form nama/peran/model terlebih dahulu. Agent dengan nama library-generated yang unik pada daftar pengguna dan avatar/default yang valid muncul setelah backend berhasil, lalu DM yang benar terbuka.
- [x] Satu pembuka otomatis dari pengguna terlihat dan diadmit untuk satu creation operation; double submit/retry/lost acknowledgement/reconnect/restart tidak menggandakan agent, DM, opener, atau admission. Opening existing chat tidak menjalankan model.
- [x] Failed initial response atau default connection yang belum siap mempertahankan agent/DM dan menyediakan perbaikan/kelanjutan pada chat yang sama; unknown native outcome tidak diulang buta.
- [x] Personalisasi menanyakan bantuan nyata secara bertahap, boleh langsung bekerja, dan tidak mewajibkan checklist nama/peran/persona/goals/cara kerja. Self-update melalui tools menampilkan feedback berhasil dan memperbarui sidebar/panel sesuai API/revision.
- [x] Klik avatar/nama membuka tab Agent; panel dapat ditutup. Mobile memakai sheet/tampilan penuh dengan jalur kembali ke chat; komponen tab/header/detail konsisten.
- [x] Memory dapat dilihat/dikoreksi/dihapus. Skills menampilkan sumber harness/app; hanya app-owned package yang dapat ditulis. Pengaturan teknis tetap bertahap.
- [x] Default pesan saat sibuk diantrekan; edit/hapus hanya sebelum diproses; Arahkan sekarang kontekstual; stop-requested dan stopped jelas; edit/delete bukan undo.
- [x] Minimum version, akun/model/billing yang dipilih, capability unsupported/unknown dan actionable error repair mudah dipahami; tidak ada silent subscription-to-key fallback.
- [x] Tidak menambah login/pairing A05, installer A01, dashboard optional B05, custom advanced editor B07, atau wizard personalisasi sebagai prasyarat chat.
