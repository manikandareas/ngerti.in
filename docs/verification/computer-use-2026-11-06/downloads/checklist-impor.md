# Checklist Impor CSV untuk Staf Gudang Baru

1. Simpan salinan file CSV asli.
2. Gunakan template impor dari aplikasi.
3. Pastikan baris pertama berisi header kolom.
4. Cocokkan nama header dengan template.
5. Pastikan semua header wajib tersedia.
6. Hapus header ganda dan kolom tanpa nama.
7. Pilih pemisah yang sesuai dengan file CSV.
8. Periksa agar isi baris sejajar dengan header.
9. Pastikan kode barang terisi pada setiap baris.
10. Pertahankan angka nol di awal kode barang.
11. Cocokkan kode barang dengan daftar barang gudang.
12. Isi jumlah stok dengan angka yang valid.
13. Pastikan satuan stok sesuai dengan barang.
14. Periksa lokasi gudang tujuan setiap baris.
15. Periksa kode barang dan lokasi yang berulang.
16. Pastikan impor menambah atau mengganti stok sesuai tujuan.
17. Tinjau pratinjau dan perbaiki semua kesalahan sebelum impor.
18. Jalankan impor sekali, lalu cocokkan stok hasilnya dengan file.
