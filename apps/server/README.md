# Harness-first application server

Bun 1.3.10, TypeScript 7.0.2, Elysia 1.4.30 and Zod 4.4.3. Run `make dev` from the repository root. See the [root guide](../../README.md), [ADR](../../docs/architecture/adr-0001-harness-first-foundation.md) and [domain/API contract](../../docs/architecture/harness-first-contract.md).

- `contracts.ts`: versioned schema registry, domain types and contract publication. Entity schemas live in each domain's `contracts.ts`; `contracts/base.ts` and `contracts/errors.ts` hold shared fields and errors.
- `store.ts`: SQLite transactions, installation ownership, command receipts, projections and event cursor.
- `lifecycle.ts`: identity/scope, admission, queue/dispatch fencing, cancellation, Routine occurrence admission, goal controls and conservative recovery.
- `conversations.ts`, `agent-instructions.ts`: atomic Tobi/DM/welcome setup, consistent conversation reads and native profile context. See the [agent/conversation API and examples](../../docs/architecture/agent-conversation-api.md).
- `workspaces/`: scoped project binding (`service.ts`), descriptor-relative access (`files.ts`, `posix.ts`), schemas and product-tool handlers. Bun compiles the adjacent fixed `openat.c` ABI wrapper.
- `agents/`: agent profile schemas and configuration product-tool handlers.
- `artifacts.ts`: immutable bytes, explicit sharing and durable native publication. See the [workspace/artifact API](../../docs/architecture/workspace-artifact-api.md).
- `learning/`: scoped facts/tombstones, immutable application skill packages, pinned assignments and trusted learning-tool handlers. See the [memory/skills API](../../docs/architecture/memory-skills-api.md).
- `groups/`: context-based model routing, authored peer tasks, durable owner requests and transactional continuation. See the [group collaboration API](../../docs/architecture/group-collaboration-api.md) and [native/fixture evidence](../../docs/development/history.md#verification-archive--2026-11-17 "Archive: docs/verification/nma-056/README.md at 043f7c9").
- `goals/`: conversational responsibilities, evidence-checked completion, durable continuation and timezone-aware Routine scheduling. See the [goal/Routine API](../../docs/architecture/goals-routines-api.md) and [verification evidence](../../docs/development/history.md#verification-archive--2026-11-17 "Archive: docs/verification/nma-057/README.md at 043f7c9").
- `harness/inherited-skills.ts`: read-only native catalogs and confined inherited package snapshots, separate from app packages.
- `background.ts`: scheduler and bounded concurrent dispatcher; injectable executor port, explicitly registered Codex and Muse adapters.
- `harness/`: broker orchestration, client interfaces (`client.ts`), prompt/context construction (`instructions.ts`), host version detection, isolated credential/process context and connection projections. `tools.ts` owns scoped leases and authorization; `mcp.ts` handles MCP negotiation and envelopes, while domain modules register their handlers. See the [broker contract](../../docs/architecture/harness-broker-contract.md).
- `api.ts`, `api/`: HTTP composition and routes grouped by domain, with shared authentication, errors and durable-command handling in `api/http.ts`.
- `config.ts`, `setup.ts`, `main.ts`: development state/bootstrap and process lifetime.

Providers cannot write projections directly. They return native observations through the application lifecycle. The [Codex adapter](../../docs/architecture/codex-adapter.md) implements native login/model discovery, scoped product tools, settings, resume, steer and cancellation; the [Muse adapter](../../docs/architecture/muse-adapter.md) uses the official SDK/MSP with isolated account/process/session state and native interactions. Both are registered explicitly. [Conversation controls, SSE and receipt recovery](../../docs/architecture/conversation-control-api.md) are implemented by NMA-053. Muse steering remains unknown after live mapping evidence; its ordinary queue is preserved. NMA-050 is Done under accepted explicit API-key billing with native permission decisions verified; Muse subscription remains unverified. [Local milestone records](../../docs/backlog/README.md) own current status. Conversational goals, durable Routine scheduling and quiet publication use the same lifecycle; see the [goal/Routine contract](../../docs/architecture/goals-routines-api.md).

NMA-054 enables confined native coding on Codex. Muse uses scoped product file tools; direct native file/shell/code/Git capabilities are unsupported in that adapter configuration. See the [verification and platform limits](../../docs/development/history.md#verification-archive--2026-11-17 "Archive: docs/verification/nma-054/README.md at 043f7c9").

The active browser/desktop/file/process path is the shared Cua Linux machine. All agents use the same retained desktop with a durable foreground input lease and separate attributed terminal processes. Private history/memory/provider credentials and saved-artifact metadata remain scoped in the backend; machine working files and attachment copies are shared. See [current architecture](../../docs/architecture/overview.md) and [machine setup/native evidence](../../docs/development/history.md#verification-archive--2026-11-17 "Archive: docs/verification/shared-machine/README.md at 043f7c9"). Earlier browser-use/VNC guides describe the original implementation only.
