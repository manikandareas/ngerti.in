## Tujuan

Menghubungkan aplikasi melalui Composio serta menyediakan riset bersumber dan pemahaman visual sesuai capability runtime.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — F05, F08, F09, B06, H03.

## Unit implementasi

1. Composio account/connection/tool discovery, assignment dan invocation melalui bridge terstruktur.
2. Native web search/read dan source-attributed results; source-backed fallback transport hanya bila memang dipilih, bukan engine lama.
3. Image/video attachment preprocessing dan capability routing sesuai dukungan model/harness.

## Acceptance criteria

- [x] Satu koneksi Composio yang diotorisasi menjalankan useful tool round trip melalui agent API; connected saja bukan acceptance operasi.
- [x] Account/tool assignment owner/agent scoped; revoke dan reconnect berlaku sebelum dispatch berikutnya.
- [x] Riset web menghasilkan sumber yang dapat dibuka dan sesuai jawaban melalui harness yang mendukungnya.
- [x] Input gambar/video diuji pada runtime yang mengiklankannya; runtime tanpa capability melaporkan unsupported, bukan memalsukan hasil.
- [x] MCP/Composio/custom host data tidak mengungkap credential ke transcript atau workspace bebas.
- [x] Generasi/edit gambar F10, document generation F11 dan preview F12 tetap opsional; tidak menjadi syarat tiket ini.
