# Riset keputusan perbaikan computer use: Jev, Harness, dan E2B

Diperiksa **23 Oktober 2026**. Ini pembacaan dokumentasi dan source primer, tanpa inference berbayar, browser fixture, atau operasi sandbox. Menajamkan [riset awal](jev-browser-e2b-2026-10-23.md) berdasarkan [audit thread f9a8](../engineering/browser-thread-f9a8-audit-2026-10-23.md). Semua workflow Ngertiin yang diusulkan di bawah **belum merupakan API upstream atau implementasi yang terbukti**.

## Keputusan utama

Pertahankan Jev sebagai pemilih operasi/target DOM yang terbatas; perbaiki supervisor Ngertiin untuk capability aktual, kepemilikan tab, kemajuan, evidence, verifikasi kandidat, dan finalisasi budget. Mengganti engine saja tidak menyelesaikan audit: resource retained v1 menghasilkan fallback screenshot dan nol panggilan Jev; tab artikel dapat ditinggalkan oleh reaktivasi target lama; draft belum tersimpan ketika reservasi berikutnya ditolak. [Bukti audit lokal](../engineering/browser-thread-f9a8-audit-2026-10-23.md).

## TypeSafe: kontrak dan pembagian tanggung jawab

[Indeks live](https://docs.typesafe.ai/llms.txt) mengarah ke `POST https://api.typesafe.ai/v1/systemone`: `model`, `state`, dan `questions` bernama; respons menyertakan `answers`, model aktual, dan usage token. `GET /v1/models` adalah discovery akun, bukan bukti entitlement dari riset ini karena endpoint berautentikasi tidak dipanggil. [API System One](https://docs.typesafe.ai/api/system-one), [list models](https://docs.typesafe.ai/api/list-models).

Dokumentasi saat diperiksa menyebut `jev-1.14.0` tersedia sejak 14 Oktober, sedangkan alias `jev-latest` masih menunjuk `jev-1.13.0` dan `jev-preview` ke `jev-1.14.0`. Keduanya model teks. **Usulan:** baseline perbaikan tetap versi eksplisit yang telah diintegrasikan; evaluasi 1.14 terpisah pada corpus Indonesia/English sebelum berpindah. Catat model yang benar-benar menjawab; jangan mengganti alias sebagai bagian perbaikan lifecycle. [Models](https://docs.typesafe.ai/models).

Confidence Choice/Score adalah ringkasan konsentrasi distribusi, bukan probabilitas bahwa seluruh Task benar atau izin bertindak; Noul tidak mempunyai confidence terpisah. Threshold bergantung akibat kesalahan dan harus dievaluasi per judgment. Angka cookbook bukan batas universal. [Confidence](https://docs.typesafe.ai/confidence). Vendor juga mencatat kelemahan 1.13 pada hitungan, perbandingan tanggal, state penuh distraktor, urutan opsi, dan konten adversarial. **Usulan:** URL/ownership, tanggal terurut, batas budget, izin dan freshness ditentukan kode; Jev menilai relevansi kandidat, dukungan klaim, atau pilihan aksi dengan opsi gagal/tidak ada yang sesuai. [Jaggedness 1.13](https://docs.typesafe.ai/model-jaggedness/jev-1.13).

Untuk riset multisumber, cookbook citation checking memeriksa keberadaan quote dengan string matching lebih dahulu, lalu Choice menilai klaim terhadap konteks sumber; hasilnya `verified`, `unsupported`, `contradicted`, atau `fabricated`. Contohnya memakai cache dan `jev-1.12`, sehingga angka demonstrasi tidak membuktikan kualitas Ngertiin. **Usulan:** simpan source excerpt dan metadata, kandidat laporan, pemetaan klaim-sumber, verdict dan alasan; lakukan pemeriksaan deterministik lalu semantic check. Screenshot terakhir tidak menggantikan input kandidat dan bukti. [Cookbook resmi](https://docs.typesafe.ai/cookbooks/citation_check).

## Target lifecycle dan readiness

CDP resmi menyediakan `Target.setDiscoverTargets` serta `targetCreated`, `targetInfoChanged`, `targetDestroyed`; `TargetInfo` memuat URL/title dan `openerId` yang **opsional**. Event pembuatan target belum menjamin URL akhirnya sudah tersedia. Data tersebut mendukung rekonsiliasi tab, tetapi CDP tidak memberi otorisasi Task. [Target protocol, revision `7245ec5`](https://github.com/ChromeDevTools/devtools-protocol/blob/7245ec551bc9d450170193456ab3965bb7e716cb/pdl/domains/Target.pdl).

Harness `0.1.13` benar-benar menyediakan `cdp()` dan `drain_events()`. Daemon merekam `method`, `params`, `session_id`; drain mengosongkan buffer bersama. Source `daemon.py` dan `helpers.py` pada pin `c6a9412` identik dengan file wheel yang diperiksa; wheel SHA-256 `2491459e4bfc0ee8aea22dc6c4680fc0f791b7ba553446323c50d2883449d769`. `wait_for_network_idle()` juga mengonsumsi buffer itu. Jadi jangan mengarang API `subscribe`; gunakan satu consumer yang mendistribusikan event atau watcher browser-CDP tersendiri bila isolasi event diperlukan. Pilihan transport masih perlu uji runtime. [Wheel terpin](https://pypi.org/project/browser-harness/0.1.13/), [helpers](https://github.com/browser-use/browser-harness/blob/c6a941287424f32e2d20c7b7b892c8493f46808d/src/browser_harness/helpers.py#L72-L80), [daemon](https://github.com/browser-use/browser-harness/blob/c6a941287424f32e2d20c7b7b892c8493f46808d/src/browser_harness/daemon.py#L626-L680).

**Workflow tab yang diusulkan:** ambil baseline target sebelum dispatch; korelasikan event/getTargets dengan receipt aksi, opener bila ada, browser identity, lease dan control epoch; tunggu URL/redirect serta main frame yang relevan; adopsi hanya target yang memenuhi policy. Jika opener tidak tersedia atau beberapa kandidat ambigu, jangan memilih tab terbaru secara otomatis. Rekonsiliasi `Target.getTargets` dengan deadline tetap diperlukan setelah reconnect/event hilang. Perubahan canonical target membatalkan proposal lama dan harus konsisten untuk DOM, screenshot, verifier, serta noVNC. Observasi tidak boleh memfokuskan tab pencarian lama sebelum hasil klik direkonsiliasi.

`Page.navigate` dapat mengembalikan `errorText`, `isDownload`, dan `loaderId`; `loaderId` tidak berubah untuk navigasi same-document. Event `frameNavigated`, `navigatedWithinDocument`, serta `lifecycleEvent` membantu membedakan transisi. **Usulan readiness:** periksa outcome navigasi dan frame/loader yang benar, lalu predicate konten yang dibutuhkan Task dalam waktu terbatas. `readyState=complete`, port hidup, maupun network idle saja tidak membuktikan artikel SPA siap dibaca. [Page protocol terpin](https://github.com/ChromeDevTools/devtools-protocol/blob/7245ec551bc9d450170193456ab3965bb7e716cb/pdl/domains/Page.pdl).

`BU_CDP_WS` mempunyai prioritas atas `BU_CDP_URL`; URL HTTP diselesaikan melalui `/json/version`. Daemon/helper membaca konfigurasi saat import. **Usulan:** endpoint eksplisit sebelum import, nama daemon per browser generation, validasi identity, dan gagal tertutup jika browser tidak tersedia. `ensure_daemon()` upstream memiliki self-healing; jangan menganggapnya admission gate yang melarang autostart. Gunakan adapter dengan kebijakan attach yang diperiksa. [Daemon](https://github.com/browser-use/browser-harness/blob/c6a941287424f32e2d20c7b7b892c8493f46808d/src/browser_harness/daemon.py#L264-L290), [wheel admin `0.1.13`](https://pypi.org/project/browser-harness/0.1.13/).

## Retained E2B v1: maintenance capability lebih dahulu

Template resmi Desktop menyediakan Chrome, display/input dan noVNC; Python 3.12/uv/Jev bukan kontrak otomatisnya. E2B mendukung build turunan `Template().from_template("desktop")` dan create menggunakan template kustom. Mengubah default template untuk create baru tidak didokumentasikan sebagai penggantian image sandbox retained. [Template terpin](https://github.com/e2b-dev/desktop/blob/a7b4cc3282bdea31b50c8b3c9a456116e734df5c/template/template.py), [custom template resmi](https://github.com/e2b-dev/desktop/blob/a7b4cc3282bdea31b50c8b3c9a456116e734df5c/template/README.md).

SDK terpasang `e2b==2.56.0` diperiksa secara statis: `commands.run(..., user=...)`, `files.write(..., user=...)`, `pause(mode="filesystem")`, dan `connect(on_resume="reboot")` tersedia. Ketiga file sumber terkait identik dengan tag `e2b@2.56.0`, commit `62a17df`. Ini membuktikan interface SDK, belum membuktikan hak root, disk/egress, envd, atau dukungan mode pada resource retained. [Commands source](https://github.com/e2b-dev/E2B/blob/62a17dfc3f11439d1d06bfb9bb515eadc5adfcd3/packages/python-sdk/e2b/sandbox_sync/commands/command.py), [filesystem source](https://github.com/e2b-dev/E2B/blob/62a17dfc3f11439d1d06bfb9bb515eadc5adfcd3/packages/python-sdk/e2b/sandbox_sync/filesystem/filesystem.py), [lifecycle source](https://github.com/e2b-dev/E2B/blob/62a17dfc3f11439d1d06bfb9bb515eadc5adfcd3/packages/python-sdk/e2b/sandbox_sync/main.py).

**Usulan jalur utama:** maintenance satu kali dengan lease eksklusif, tanpa agent/takeover aktif. Validasi capability; pasang Python/uv/runner terpin pada direktori versi tersendiri di `/opt`; periksa hash dan smoke capability tanpa mengganti Chrome/profil; switch manifest/pointer secara atomik dengan rollback; flush writes. Setelah maintenance berhasil, probe pause/resume dan cold boot secara terkontrol sebelum menandai capability siap. Pertahankan template identity asli dan catat capability version terpisah; resource baru memakai baked v2. Tidak ada instalasi dependency per Task. Jalur ini perlu dirancang serta diuji sebagai workflow aplikasi, bukan disebut `migrate_template()`.

Full pause mempertahankan filesystem dan RAM; filesystem pause membuang proses dan cold boot. Semua koneksi eksternal harus dibuat ulang. `mode` tersedia sejak SDK 2.55, tetapi penolakan feature/team/node tetap mungkin. `on_resume="reboot"` juga memerlukan dukungan control plane dan hanya mempertahankan write yang sudah di-flush; keberhasilan method saja belum membuktikan boot mode. Proses desktop/runner harus dapat dinyalakan kembali dari disk. [Filesystem persistence](https://docs.e2b.dev/sandbox/filesystem-only-snapshots), [reboot semantics](https://docs.e2b.dev/sandbox/resume-without-memory).

E2B kini mendokumentasikan `create_snapshot()` dan `fork()` untuk menggandakan **state yang sama**, termasuk syarat envd `>=0.5.0` bagi snapshots. Ini dapat menjadi checkpoint jika capability memungkinkan, tetapi bukan API yang menggabungkan filesystem v1 ke template v2. [Snapshots](https://docs.e2b.dev/sandbox/snapshots), [fork](https://docs.e2b.dev/sandbox/fork).

**Jalur sekunder:** bila maintenance tidak mungkin, rancang ekspor/import file ke resource baru melalui API filesystem, dengan penghentian penulis dan backup terlebih dahulu. Chromium menjelaskan user-data-dir berisi cookie, profil dan local state, serta dua instance tidak boleh berbagi direktori aktif. Tidak ada jaminan portabilitas login dari sumber ini. Pin versi Chrome/OS, pertahankan owner dan konteks key storage yang diperlukan, uji pada salinan sintetis, dan sediakan reautentikasi bila sesi tidak dapat dipindahkan. Jangan menghapus resource/profil lama sebelum validasi serta keputusan cutover. [E2B file I/O](https://docs.e2b.dev/filesystem/read-write), [Chromium user data](https://chromium.googlesource.com/chromium/src/+/main/docs/user_data_dir.md). CDP tetap privat dan memakai custom user-data-dir sesuai perubahan Chrome 136. [Chrome remote debugging](https://developer.chrome.com/blog/remote-debugging-port).

## Gate penerimaan yang relevan dengan kegagalan

Berikut **usulan acceptance**, bukan hasil pengujian dokumen ini:

1. **Capability/engine:** retained v1 yang belum dimutakhirkan melaporkan alasan eksplisit; v1 sesudah maintenance dan create v2 benar-benar menghasilkan keputusan TypeSafe dan ledger model aktual. Manifest cocok sesudah warm/cold resume, tanpa perubahan data profil yang tidak disengaja.
2. **Kepemilikan tab:** ordinary link, `target=_blank`, `window.open`, redirect, opener hilang, beberapa popup, close/reconnect, dan tab manusia saat takeover. DOM/screenshot/verifier/viewer setuju tentang target; epoch lama tidak dapat mengadopsi atau mengklik tab.
3. **Kemajuan kedua engine:** artikel SPA lambat, sumber tertutup/paywall, klik tanpa efek, siklus pencarian-artikel dan revisit yang sah. Pakai fingerprint, kunjungan, receipt hasil, serta pertambahan evidence; setelah batas tanpa kemajuan, replan/escalate dengan alasan. Jangan menilai progress dari deskripsi aksi saja.
4. **Hasil riset:** dua–tiga situs termasuk tab baru; simpan URL/final URL, title, waktu akses, tanggal sumber bila tersedia, excerpt, temuan dan kandidat sebelum verifikasi. Klaim terfabrikasi/kontradiktif/unsupported harus gagal atau inconclusive; kandidat dan verdict tetap dapat diaudit ketika koreksi gagal. Waktu runtime dan perbandingan tanggal ditangani eksplisit.
5. **Budget/fault:** replay kondisi audit: sisa `23.376` dan reservasi `26.630` setelah pemakaian `36.624/60.000`. Sisihkan budget untuk sintesis/verifikasi/finalisasi; tanpa ruang aksi baru, checkpoint dan hasil parsial jujur/blocked-budget harus tersedia. Tidak boleh menandai draft tersimpan bila kosong. Uji model timeout/429/529, cancellation dan takeover terhadap late result serta dispatch; retry tetap tunduk budget/lease. [Kondisi audit](../engineering/browser-thread-f9a8-audit-2026-10-23.md), [error API TypeSafe](https://docs.typesafe.ai/api/errors).

Pin Jev source `1231850`, wheel Harness `0.1.13` beserta hash, SDK E2B `2.56.0`, template build, Chrome/Python/runner dan model ID. Ukur keberhasilan yang diverifikasi, false finish, loop, fallback, pemulihan, biaya per provider serta p50/p95 pada corpus yang sama; tetapkan target dari baseline. Dokumen ini tidak mengklaim benchmark upstream berlaku pada Ngertiin, threshold confidence universal, atau keberhasilan migrasi/login/end-to-end.
