## Objective

Complete the contextual product workflows around the native conversation without changing the accepted information architecture or losing scope, draft, selection and reading state.

## Implementation units

1. Implement Detail for agent/group/member profiles, shared directions, connection/model configuration and contextual Goals/Routine lists/details/controls. Keep stop run versus stop responsibility distinct and present backend-confirmed updates.
2. Implement Library saved results/details/sharing plus contextual memory and inherited/app-owned skills. Preserve scope, provenance, correction/archive/rollback and current capabilities; app workflows do not overwrite inherited skill packages.
3. Implement in-place General/Providers/About Settings, theme, provider/account selection, login/callback/repair states, defaults and reasoning/model options. Preserve current navigation state and the original view/focus when Settings closes.
4. Implement Composio connection/grant and authorization flows with exact target/account/capability state. Use existing backend operations and safe native external navigation; do not introduce new app integrations or billing fallback.
5. Implement the dedicated Working files tree opened beside panel Close, with lazy directory reads, per-folder append pagination, retry/refresh, keyboard behavior, source-format icons and retained expansion/selection/focus/scroll. Library remains scoped saved results; machine files remain cooperatively shared.
6. Compose Focus for saved results, sent/local attachments, Working files and maximized tables. Preserve overlay header, centered filename, floating composer/context chip, nested Back/info/download, reading state and submit-time attachment linkage.

## Acceptance criteria

- [x] Detail/Library/Computer labels, nested pages, Working files entry and compact-window sheets follow the reference. Back/Escape/Close restore the correct originating control and location without clearing the composer.
- [x] Agent versus group/member identity/settings and Goals/Routine operations consume authoritative scoped revisions. Global member profiles or DM-private resources do not change or leak through group configuration.
- [x] Memory, skills, saved-result information/sharing and Composio state expose only implemented capability-valid operations. Failure/retry preserves user input and does not suggest a successful external operation before confirmation.
- [x] Settings opens in place from the existing workspace, restores selected section/provider, and returns to the same context. Login/account/catalog/defaults/effective billing are distinct; unsupported or unavailable options remain explicit.
- [x] Working files loads on expansion, appends/retries within the correct folder and refreshes removed references. Scope changes cancel retired reads; Focus Back preserves tree expansion, selected item, scroll and keyboard focus. Format icon precedence and theme variants match current assets.
- [x] Focus directly renders the selected file/table type using NMA-067 components. Nested table Back returns to its document first; normal Back restores the conversation or originating Library/tree and its reading state. Original downloads are byte-identical.
- [x] Removing a context chip submits ordinary feedback. Accepted contextual feedback returns to the same chat with the authoritative file reference/artifact IDs; rejected submissions restore editable input. Working-file/table snapshots are staged only on Send and retries create no duplicate contextual copy.
- [x] Real-API native journeys cover DM/group scopes, selected account/model repair, files/PDF/HTML/source/tables, responsibility and pending interaction states, including failures/reconnect. External login/provider/Composio outcomes not exercised remain explicitly unverified.
- [x] Detail/Library/Settings/provider forms, tree, Focus header/menus/context chip/composer and PDF controls are native GPUI. An HTML WebView is restricted to the selected document body and cannot supply surrounding application chrome or forms.
