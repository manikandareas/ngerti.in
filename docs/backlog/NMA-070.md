## Objective

Bring the shared Computer and desktop-host responsibilities to the native client, preserving server-owned leases, process ownership and the current close/hide/reopen/quit behavior.

## Implementation units

1. Adapt profile validation/private writes, single-instance focus, compatible backend discovery, attach-or-own supervision, liveness/readiness, bounded recovery, redacted diagnostics and process shutdown. Use a distinct desktop-rs namespace and existing backend authority locks.
2. Implement native menus/tray, editing actions, zoom/fullscreen, restored on-screen window geometry, safe external URLs and collision-safe downloads. Map Reload/Developer Tools to documented native reconciliation/diagnostics and embedded-surface inspection rather than exposing arbitrary runtime execution.
3. Embed the existing Cua viewer through the proven WebView adapter, with compact/expanded Computer surfaces and native overlays/focus. Maintain read-only versus interactive capability, exact control revision, ticket expiry/renewal and decoded-frame health/reconnect.
4. Port human takeover/handback and consent/question controls using authoritative server operations; retire stale surfaces and transfers. The retained machine is never provisioned/deleted by this client and desktop Quit does not stop the shared machine.
5. Wire native hide/minimize/close/reopen/sleep/wake/quit signals to avatar/event/media suspension, view revocation and exact-lease release even when embedded content is suspended. Refresh authoritative state on return without resubmitting input.
6. Enforce narrow preview/viewer integration: private native transport authentication, scoped media gateway where needed, static-document restrictions, origin/source validation, and no generic credentials/shell/filesystem bridge to web content.

## Acceptance criteria

- [x] Second launch focuses the existing desktop-rs window. Compatible external backends are attached without duplicate processes; startup refuses incompatible/locked ownership safely and displays an actionable error without resetting data.
- [x] Close hides the window while backend work continues; Show/Reopen returns to the same workspace. Quit gracefully stops only owned services, leaves an external backend alive and retains Goals/Routine definitions. Crash/restart tests reconcile receipts before replay.
- [x] Editing/clipboard, zoom/fullscreen, menus/tray, geometry and safe downloads work on the reference OS. Refresh and diagnostics preserve drafts and do not grant preview content new native privileges.
- [x] Actual retained-machine frames are decoded in both Computer surfaces; connection text alone is not accepted as media proof. Native menus/dialogs/contextual composer paint above and receive focus correctly around the embedded surface.
- [x] Read-only cannot send foreground input. Human takeover and handback bind to current lease revisions; disconnect/expiry/revocation block stale input and recovery obtains fresh tickets without blind mutating retries. Takeover/renewal/reconnect are proved separately from the earlier read-only experiment.
- [x] Hide/minimize/close and best-effort sleep cleanup revoke this client's tickets and release only its exact human lease, including when browser JavaScript is paused. Reopen/wake refreshes state and never restores a stale grant. The shared machine remains available.
- [x] Embedded content receives no installation credential, broad IPC bridge or unauthenticated machine endpoint. Downloads/origins/health messages and native callbacks are checked against the actual current surface/session.
- [x] Host/API/native media evidence records pins, ownership, failures and actual control cleanup. Physical sleep/wake and platform-specific checks remain unexecuted until observed; Windows/Linux are not inferred from macOS or upstream support.
- [x] Only HTML document content and the scoped Computer viewer instantiate WebViews. The Computer panel, surrounding navigation and application actions remain native GPUI; the viewer's protocol-owned controls do not receive broad native access.
