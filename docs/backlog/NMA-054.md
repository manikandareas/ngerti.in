## Tujuan

Agent bekerja pada file/proyek yang benar dan menghasilkan artifact melalui kemampuan harness tanpa membocorkan host atau secret.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — F01, F02, F03, F04, H03.

## Unit implementasi

1. Scoped workspace/project binding dan staging/upload/download artifact.
2. Expose file/read/write/search serta terminal/code/Git melalui native harness capability yang sesuai.
3. Resource authorization dan artifact provenance pada final dispatch/publication.

## Acceptance criteria

- [x] File input dapat dibaca dan artifact output diunduh melalui API dengan owner/agent/thread scope yang benar.
- [x] Dua workspace atau DM/grup tidak saling membaca/menimpa resource privat tanpa sharing eksplisit.
- [x] Native file/terminal/code/Git yang diiklankan didemokan melalui harness terpilih; bukan parsing klaim prose selesai.
- [x] Symlink/path escape/foreign artifact/credential directory tidak menjadi akses bebas; secret tidak dikirim ke transcript.
- [x] Pembatalan/restart tidak menggandakan publication atau menghapus file lain; data baru tetap persisten.
- [x] Tidak mengerjakan computer use umum, preview UI atau installer.
