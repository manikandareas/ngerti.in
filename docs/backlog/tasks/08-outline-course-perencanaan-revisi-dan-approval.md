## Acceptance criteria

- [ ] Outline menyatakan tujuan, node dan aktivitas berdasarkan kebutuhan belajar serta sumber terpilih.
- [ ] Revisi melalui chat mempertahankan outline sebelumnya sampai revisi tervalidasi siap.
- [ ] Approval terikat revision yang ditinjau dan mereservasi satu Course secara idempotent.
- [ ] Cakupan luas dapat ditawarkan sebagai beberapa Course koheren sebelum approval; outline disetujui tidak dipotong karena billing.
