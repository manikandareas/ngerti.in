Membuktikan pengalaman produk wajib melalui browser nyata setelah engine/API dan implementasi UI selesai.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — T06, A03, H02, H03, H05, H06.

## Unit implementasi

1. Walkthrough desktop/mobile untuk satu halaman percakapan, daftar agent/grup/chat di kiri, tombol +, dan sidebar kanan Agent/Anggota, File, Goals, Routine.
2. Create-agent langsung dan create-group dialog; automatic opening, personalisasi yang bisa dilewati, scoped tool updates dan sinkronisasi panel.
3. Queue/steer/stop, group/HITL, goals/Routine, file/artifact, VNC, Composio serta supported visual input melalui API nyata.
4. Restart/reconnect/lost acknowledgement/opening failure/limit/error/revoke dengan assertions lintas UI dan backend; reconcile matriks dan batas Opsional/Tunda.

## Acceptance criteria

- [ ] NMA-083 is Done for the [server-organizations plan](../architecture/server-organizations-plan-2026-11-12.md); full-product acceptance uses the current PostgreSQL/auth/multi-user web/Tauri contract, including private data and execution-domain boundaries. Further desktop-rs work is not a dependency.

- [ ] NMA-061/NMA-062 Done dan NMA-060 tetap valid pada versi UI, termasuk prerequisite NMA-065.
- [ ] Desktop/mobile memakai kerangka percakapan yang sama. Sidebar agent sekaligus chat; tidak ada halaman Agents atau Workspace/Goals/Routine global wajib. Panel tab clean, dapat ditutup dan digunakan sebagai sheet/tampilan penuh pada ponsel.
- [ ] Tombol + berisi Create agent dan Create group. Agent langsung dibuat bernama acak dari library tanpa form; grup memakai dialog nama/agent.
- [ ] Kedua flow membuka percakapan yang tepat dan satu automatic user opener yang terlihat. Double submit, creation retry, lost acknowledgement, reconnect/restart dan opening ulang tidak menggandakan entity, opener, atau admission.
- [ ] Failed initial response/default connection unavailable mempertahankan entity dan menawarkan kelanjutan pada chat yang sama; unknown native effect tidak diulang buta.
- [ ] Personalisasi sesuai kebutuhan nyata: satu pertanyaan saat perlu, dapat langsung melakukan tugas, tanpa checklist wajib nama/peran/persona/goals. Successful tool update tercermin di sidebar/panel.
- [ ] Group opening dipandu satu anggota; nonselected agent diam. Group instructions tidak menulis profil global seluruh anggota atau membocorkan DM-private memory/history/files.
- [ ] File/Goals/Routine dan detail mengikuti agent/thread/group scope; artifact/VNC, handoff/HITL serta quiet/proactive results kembali ke konteks benar.
- [ ] Walkthrough menggunakan Codex/ChatGPT dan Muse Code, termasuk grup lintas harness; catat exact API/native versions, setup, denominator, failure/skip/unknown. Screenshot/build/typecheck saja bukan acceptance.
- [ ] Stop/recovery/credential/capability/error sesuai backend receipts; tidak ada mandatory goal activation, silent billing switch, atau penulisan native skills bawaan.
- [ ] Hasil hanya readiness produk development. Installer/perangkat lain tetap setelah tiket ini; Opsional/Tunda tidak menjadi gerbang tersembunyi.
