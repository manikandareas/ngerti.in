## Implementation and ownership

The renderer-independent avatar crate implements version-1 recipes, JavaScript UTF-16 length bounds, Unicode scalar hashing, wrapping u32 randomness, all eight shapes/eight faces/twenty legacy-valid colors, 8,500 seeded fibers, expression/state/action/loading samplers, independent blink and smoothing. The native window shares one `AvatarAnimator`; its bounded worker composites cached material and independent eye/ornament layers. The worker queue holds one job, material cache sixteen identities and prepared surfaces thirty-two entries. Scene retirement cancels measurements/tasks and releases images. Visibility, content-mask intersection, compact size and system/component reduced motion control sampling. The main UI, editing, document controls and PDF rendering are Rust/GPUI; only a sanitized static HTML body constructs a WebView.

The composer owns native text/reference editing separately from submission policy. Agent/user/file/skill references retain their typed metadata and exact wire URLs. Selection/editing normalizes grapheme and token boundaries; clipboard JSON is validated and bounded at 4 MiB. Reference registration retires deleted non-catalog metadata; history retains at most 128 snapshots and 8 MiB of text/reference strings, except the current single oversized draft. Undo/redo, suggestions and file/drop inputs emit local intents. Live submission, durable per-thread storage and scoped upload remain NMA-068; none is simulated as a successful backend operation.

Message components supply user/assistant and DM/group attribution, file-only content, source/reference links, safe activity labels, loading shimmer, error/retry and revision-bound question/approval controls. The public activity enum has no raw tool observation or handoff-instruction field. Publication labels match the current client's `id-ID` formatter and device-local publication day/clock; frozen tests cover midnight, year boundaries, timezone offsets and invalid inputs.

Interaction answers retain selected IDs and custom Unicode text. Rules cover required/optional, single/multiple and alternative/additional custom answers, unique known choices and UTF-16 limits. A stale rendered request/revision is rejected at dispatch; an uncertain response exposes status checking rather than automatic replay. Submitted/resolved presentation uses the authoritative answer value. The gallery emits local intents only.

Source and tables prepare models off the UI thread. Source retains original bytes separately from normalized display newlines, matches the current filename/language mappings, uses the frozen original Shiki palette with native Syntect grammars, and supplies precomputed UTF-8 highlight runs to a read-only virtual editor. Bounded truncated source remains readable with an explicit preview warning; UTF-8 tails split by the preview limit are omitted without accepting invalid interior bytes. Find is literal, per-line and lowercased; wrap/line numbers and original copy are native. Tables parse quoted CSV/TSV, reject ragged columns, enforce 200 columns/100,000 rows/500,000 cells, skip empty lines, preserve original bytes, sort/filter off-thread, retain stable ties and exact large-integer ordering, use native locale-aware collation, infer numeric alignment/column widths and virtualize variable-height rows. Mouse/keyboard ranges copy TSV; expanded native dialogs carry filter/sort/wrap/selection back to their parent.

Image decoding runs in background and retains original download bytes. It bounds compressed input to 16 MiB, decoded images to sixteen million pixels, dimensions to 16,384 and decoder allocation to 128 MiB. Native fit/zoom and PNG clipboard are separate from original download.

PDF uses one eight-MiB OS worker for immutable file loading, Quartz geometry/rasterization and a one-slot job queue. PDFKit handles text interpretation on the main thread; GPUI owns continuous virtual pages, selection highlights, paging, fit/50–200% zoom and fractional reading anchors. The LRU retains at most five page rasters/four million pixels per raster. A generation fence discards retired work; replaced/hidden rasters are explicitly dropped. Protected/malformed/size/page-limit cases expose retry/original download. No browser PDF fallback exists.

HTML preparation ports the actual `html-preview.ts` policy through html5ever. It strips executable elements, event attributes, navigation/form targets and unsafe document metadata, and enforces restrictive CSP. The only browser adapter accepts the typed prepared body, disables JavaScript/IPC/devtools/download/new-window paths, uses an incognito context and permits only blank/local-anchor navigation. Original downloads use the untouched fixture bytes.

## Failures and measurement boundaries

The [initial report](avatar-slice.md) retains the verified resvg 0.46.0 displacement defect and exact sqrt(5) adapter correction. Exported SVG keeps the original five-unit filter. Cross-rasterizer antialiasing/resampling remains separate from seed/geometry equivalence.

The first continuous native iteration used unoptimized scalar rasterization and delivered only about seven new images per second despite a 60 Hz window redraw. The optimized bicubic iteration still delivered about thirty images per second; both failed iterations remain under `components/failed-debug-*` and `components/bicubic-iteration`. Native presentation evidence must count actual image changes, not redraw callbacks alone. Bilinear cached composition reduces the diagnostic CPU cost, but [headless results](components/headless-compositor.json) alone cannot establish delivered native cadence.

Two Tauri reference cohorts were rejected: the first had an 869-point document viewport, and the second omitted the original avatar stylesheet so SVGs remained 200 pixels instead of 32/128. Their raw records remain in the named iteration directories. The current harness loads the actual stylesheet, validates every host/SVG rectangle, texture readiness and viewport/scale, and requires both native and document visibility. Version-3 records reject zero updates, zero frames, long unexplained frame gaps and normal workloads captured under reduced motion. Hidden time pauses the denominator.

Native `request_animation_frame` is only legal during render: calling it from an asynchronous/visibility callback caused a crash. The adapter now registers `on_next_frame` from those callbacks and requests animation only in a visible, non-reduced portrait render. Absolute canvas origins were also corrected before the retained PDF selection and native gaze work. Quartz's drawing transform did not upscale pages; explicit natural-to-pixel scaling plus a nonwhite-bounds regression corrected the first undersized PDF raster.

No inference/provider/billing/Computer/installation/production acceptance is exercised by this gallery. The active Tauri client, existing credentials/profile/database and unrelated files were preserved. Temporary test profiles contain fixture artifacts only.
