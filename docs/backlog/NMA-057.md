## Tujuan

Tanggung jawab muncul otomatis dari percakapan dan berlanjut secara persisten melalui Routine saat tab tidak dibuka.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — E01, E02, E03, E04, E06, E07, E08, A04.

## Unit implementasi

1. Structured capture/update/stop tools dan multi-goal domain persistence lintas sesi.
2. Satu continuation/scheduler owner, Routine one-shot/recurring/heartbeat, timezone dan wait/blocked/quiet.
3. Evidence-based completion, stop goal vs stop run, durable occurrence identities dan publication.

## Acceptance criteria

- [x] Chat biasa menangkap tanggung jawab nyata tanpa form/command/activation button; koreksi mengubah goal yang sama, hipotetis tidak otomatis menjadi komitmen.
- [x] Beberapa goal per agent memiliki thread/source/progress/evidence sendiri dan bertahan setelah restart.
- [x] Routine satu kali/berulang/heartbeat dibuat dan diubah melalui percakapan; server aktif dapat menjalankan saat tab tertutup.
- [x] Goal selesai hanya dengan hasil/bukti, atau menyatakan wait/blocked; quiet tick tidak mengirim spam.
- [x] Stop goal mematikan kelanjutan dan occurrence lama, sedangkan stop run punya scope terpisah; keduanya bertahan restart.
- [x] Scheduling/handoff/retry tidak memunculkan owner kedua atau duplicate effects; jangan menyalin routine Openbot sebagai bukti automatic goal capture Ngertiin.
- [x] Webhook E05 tetap opsional dan bukan syarat selesai.
