## Tujuan

Membuat instalasi pada perangkat lain mudah setelah seluruh engine/backend, API, UI dan acceptance produk wajib selesai.

## Dasar keputusan

[🧭 10 · Matriks keputusan fitur · Harness-first](../product/feature-decisions.md) — A01, T05.

## Unit implementasi

1. Pilih target OS/package/installer berdasarkan dev runtime yang sudah terbukti; ini urutan terakhir rangkaian wajib.
2. Fresh-device setup untuk backend web, persistence, harness detection/minimum version, login dan background process.
3. Dokumentasi install/update/uninstall serta diagnostics dan capability prerequisites.

## Acceptance criteria

- [ ] Hanya dimulai setelah NMA-063 Done; tidak mendahului pekerjaan fitur produk atau mengubah pilihan minimum version tanpa bukti.
- [ ] Fresh local install dapat membuka web, menghubungkan satu harness, menjalankan DM/tool/goal dan bertahan restart.
- [ ] Entry web menggunakan percakapan/sidebar/panel yang telah lolos NMA-063; create-agent dan create-group/opening dapat dilanjutkan setelah restart tanpa mengulang onboarding. Installer tidak memperkenalkan halaman Agents/Workspace atau wizard personalisasi baru.
- [ ] Folder data/secret dan process lifecycle jelas; binary/container tidak dianggap otomatis mewarisi CLI/login host.
- [ ] OS/support matrix, upgrade dan uninstall behavior didokumentasikan berdasarkan pengujian nyata.
- [ ] VPS A02 tetap opsional dan bukan syarat tiket ini; remote host X03, native apps X06 dan full access auth A05 tidak diam-diam dimasukkan.
- [ ] Tidak membutuhkan migrasi data development lama; data baru pengguna tidak dihapus oleh upgrade normal.
